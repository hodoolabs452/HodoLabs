# HodoLabs — Official Main Website

Official corporate website for **HodoLabs** — a technology and product company building modern digital learning and assessment experiences.

## Architecture

This project is the main brand website for HodoLabs. It operates independently from our dedicated learning portal, **[HodoLabs Learn](https://learn.hodoolabs.com)**.

- **Framework**: [Next.js](https://nextjs.org/) 15+ (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **SEO**: Static page generation, OpenGraph metadata, JSON-LD Schema, dynamic sitemap and robots.txt.

## Pages

- **Home** (`/`): Company vision, HodoLabs Learn product spotlight, interactive assessment preview, pedagogy, and company principles.
- **About Us** (`/about`): Why HodoLabs exists, product-first philosophy, vision, and mission.
- **Products** (`/products`): Showcase of HodoLabs Learn as our primary live learning & assessment platform.
- **Contact Us** (`/contact`): Inquiry form and direct connection via `hello@hodoolabs.com`.
- **Privacy Policy** (`/privacy-policy`): Student data privacy and data handling practices.
- **Terms of Service** (`/terms-of-service`): Terms governing digital platform usage.

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run linter
npm run lint

# Build production bundle
npm run build
```
